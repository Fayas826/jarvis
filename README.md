# JARVIS AI ⚡

A futuristic AI assistant system with:

## Features
- Multi-agent AI (CrewAI)
- 3D holographic UI (React + Three.js)
- Voice interaction
- Dynamic UI modes (HUD, Reactor, Grid)
- Sound + animation system

## Tech Stack
- FastAPI (Backend)
- React + Tailwind (Frontend)
- Three.js (3D)
- OpenAI API

## Run Project

### Backend
cd backend
uvicorn api:app --reload

### Frontend
cd frontend
npm install
npm run dev
