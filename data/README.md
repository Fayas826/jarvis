# CognitiveOS Dataset Strategy & Registry

This directory contains the dataset strategy structure to support evaluation, grounding experiments, and autonomous agent benchmarking.

## Directories

* `/vision` — General vision metadata and local snapshot logs.
* `/gui_grounding` — ScreenSpot & ScreenSpot-Pro metadata configurations.
* `/web_agent` — Trajectory mappings and task templates.
* `/evaluation` — Standard computer use benchmark suites.
* `/samples` — Sample screenshots and grounding coordinate files.
