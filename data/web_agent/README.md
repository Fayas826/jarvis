# Web Agent Trajectory Datasets

This registry lists resources and interaction models for web execution tracking.

## Mind2Web
* **Official Source:** OSU NLP Group (https://osu-nlp-group.github.io/Mind2Web/)
* **License:** CC BY 4.0
* **Purpose:** Web-agent task trajectories and DOM-based element extraction benchmarks.
* **Storage Requirements:** ~15GB
* **Status:** Reference Only (Do not download full raw package locally to avoid disk saturation).
