# GUI Grounding Dataset Registry

This directory contains metadata and download links for the ScreenSpot and ScreenSpot-Pro evaluation benchmarks.

## ScreenSpot
* **Official Source:** https://github.com/PRIS-CV/ScreenSpot
* **License:** Apache 2.0
* **Purpose:** GUI Grounding Benchmark (mapping icons and text to mouse coordinates).
* **Storage Requirements:** ~100MB
* **Status:** Grounding configurations registered.

## ScreenSpot-Pro
* **Official Source:** PRIS-CV
* **License:** MIT
* **Purpose:** High-resolution professional GUI grounding.
* **Storage Requirements:** ~300MB
* **Status:** Registered (Download on demand).
